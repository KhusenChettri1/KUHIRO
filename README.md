# 🎵 नेपाली संगीत - पहाडी धुन

## कसरी चलाउने (How to Run)

### Step 1 — Install Node.js
Download from: https://nodejs.org  
Install the **LTS** version (Windows 64-bit .msi)

### Step 2 — Open Terminal in this folder
Right-click the `web` folder → "Open in Terminal"  
OR open PowerShell and type:
```
cd C:\Desktop\web
```

### Step 3 — Start the server
```
npx serve . -l 3000
```

### Step 4 — Open in browser
Go to: **http://localhost:3000**
